# QuickLoan Demo Website

QuickLoan Demo is a mobile-friendly loan application demonstration website built using Python, Flask, HTML, CSS, and SQLite.

## Features

- User-friendly homepage
- Online loan application form
- Application reference numbers
- Application status checking
- Admin login and dashboard
- Application status management
- Temporary admin links with expiry and revocation
- Responsive design for mobile phones and computers

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- SQLite
- GitHub
- Render

## Installation

1. Clone or download this repository.
2. Install Python 3.10 or later.
3. Install the required packages:

   `pip install -r requirements.txt`

4. Configure your admin username, password, and secret key using environment variables.
5. Start the application:

   `python app.py`

6. Open your browser and visit:

   `http://127.0.0.1:5000`

## Deployment

This project includes a `render.yaml` configuration file to help with deployment on Render.

Upload the project to GitHub, connect the repository to Render, and configure the required environment variables.

## Security Notice

This is a demonstration project, not a real lending service. It does not issue loans or process financial transactions. Never enter mobile-money PINs, banking passwords, or verification codes.

Use your own branding and protect all administrator credentials.
